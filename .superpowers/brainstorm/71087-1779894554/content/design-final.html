3. 数据模型

Supabase 表结构

pm_doc_comments

  • id: uuid (主键)
  • doc_slug: string (关联文档，如 "guide-token")
  • user_id: uuid (关联 pm_users)
  • content: text (评论内容)
  • created_at: timestamp

查询时 JOIN pm_users 获取用户昵称和头像

4. 技术要点

  • 评论使用 Next.js API Route 处理 CRUD
  • 使用 Supabase 存储评论数据
  • 服务端获取评论列表，客户端提交新评论
  • 提交后乐观更新或刷新评论列表
  • 支持基本的 XSS 防护（内容转义）
