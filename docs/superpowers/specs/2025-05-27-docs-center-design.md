# 文档中心（Docs Center）设计方案

**日期:** 2025-05-27
**状态:** 已批准，待实施

---

## 1. 概述

### 1.1 目标
构建一个可扩展的文档/帮助中心，用于承载 PayModels 的产品文档，包括常见问题（FAQ）、使用指南、退款政策、支付方式说明等。文档中心采用「内容在左、导航在右」的布局，支持长文阅读和用户评论。

### 1.2 范围
- `/docs` 路由下的所有文档页面
- 导航组件（右侧 sidebar）
- 面包屑导航
- 移动端汉堡菜单
- 文档评论系统（需要登录）

## 4. 视觉设计

### 4.1 主题
沿用现有 shadcn 设计系统：
- `bg-background` / `text-foreground` 基础色
- `bg-muted/30` 右侧 sidebar 背景
- `border-border` 分隔线
- `text-primary` + `font-medium` 当前页面高亮

### 4.2 组件使用
- `Separator` — 分隔线（内容区与评论区、导航分组之间）
- `Card` — 评论卡片
- `Avatar` — 用户头像
- `Button` — 登录按钮、发表按钮
- `Textarea` — 评论输入框
- `Badge` — 可选，用于标记新评论

### 4.3 排版
- 内容区最大宽度 `max-w-3xl`
- 文章标题：`text-3xl font-bold`
- 章节标题：`text-2xl font-semibold`
- 正文：`text-base leading-relaxed`
- 使用 `gap-*` 控制间距，避免 `space-x-*` / `space-y-*`

## 5. 右侧导航（Sidebar）

### 5.1 功能
- **上半部分：全局文档导航**
  - 按分组展示所有文档页面
  - 支持展开/折叠分组（Accordion 或手风琴样式）
  - 当前页面高亮显示
  - 点击跳转对应文档页面

- **下半部分：本页目录（TOC）**
  - 自动提取当前页面中的 h2/h3 标题
  - 生成锚点链接
  - 滚动时高亮当前可见的章节
  - 点击平滑滚动到对应位置

- 两部分之间使用 `Separator` 分隔

### 5.2 交互
- 桌面端：`position: sticky; top: 5rem`
- 移动端：点击 ☰ 展开 overlay 面板
- 当前页面在导航中高亮

## 6. 内容展示

### 6.1 长文阅读
- 不使用手风琴/折叠，所有内容直接展开
- 使用清晰的 h1/h2/h3 层级结构
- 段落之间保持充足间距

### 6.2 FAQ 页面
将现有 `app/components/FAQ.tsx` 中的 6 个问题迁移为长文格式：
- 每个问题作为 h2 标题
- 答案作为正文段落
- 保留原有的信任和安全声明

### 6.3 面包屑
每个文档页面顶部显示面包屑：
```
首页 > 文档 > [分组名] > [页面标题]
```

## 7. 评论系统

### 7.1 功能需求
- **仅登录用户**可发表评论
- 评论按**时间倒序**排列
- **简单时间线**，不支持回复/嵌套
- 评论显示：用户头像、昵称、时间、内容

### 7.2 状态流转

```
未登录用户
  └─> 看到提示「登录后发表评论」
      └─> 点击 Google 登录 / 邮箱登录
          └─> 登录成功后显示评论输入框
              └─> 输入内容并点击「发表评论」
                  └─> 评论实时显示在列表顶部
```

### 7.3 UI 状态

**状态 A：未登录**
```
┌──────────────────────────────┐
│  登录后发表评论              │
│                              │
│  [Google 登录] [邮箱登录]    │
└──────────────────────────────┘
```

**状态 B：已登录 + 发表评论**
```
┌──────────────────────────────┐
│  [头像] 用户名               │
│  ┌────────────────────────┐  │
│  │ 输入评论内容...         │  │
│  └────────────────────────┘  │
│  以 用户名 发表评论    [发表]│
└──────────────────────────────┘
```

**状态 C：评论列表**
```
┌──────────────────────────────┐
│  [头像] 用户昵称 · 2小时前   │
│  评论内容...                 │
├──────────────────────────────┤
│  [头像] 另一个用户 · 5小时前 │
│  评论内容...                 │
└──────────────────────────────┘
```

### 7.4 数据模型

**表名：** `pm_doc_comments`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | uuid | 主键 |
| `doc_slug` | string | 关联文档标识，如 `"guide-token"` |
| `user_id` | uuid | 关联 `pm_users` 表 |
| `content` | text | 评论内容 |
| `created_at` | timestamp | 创建时间 |

查询时 JOIN `pm_users` 获取用户 `name` 和 `avatar_url`。

### 7.5 API 设计

- `GET /api/docs/comments?slug={doc_slug}` — 获取某文档的评论列表
- `POST /api/docs/comments` — 发表评论（需要登录）
  - Body: `{ slug: string, content: string }`

### 7.6 安全
- 服务端验证用户登录状态
- 评论内容转义，防止 XSS
- 限制单用户评论频率（可选，V2 阶段）

## 8. 可扩展性

### 8.1 导航配置化
导航数据使用配置数组，新增文档只需添加一条配置即可自动出现在导航中。

### 8.2 未来可扩展功能
- **全文搜索** — 在导航顶部添加搜索框
- **评论回复** — V2 支持嵌套回复
- **评论点赞** — V2 支持点赞功能
- **文档版本** — 支持文档版本历史
- **多语言** — i18n 支持

## 9. 技术栈

- **框架:** Next.js 16.2.6 App Router
- **样式:** Tailwind CSS v4 + shadcn/ui 组件
- **数据库:** Supabase（复用现有配置）
- **认证:** NextAuth.js（复用现有 Google + Credentials 登录）
- **字体:** Geist（复用现有配置）
